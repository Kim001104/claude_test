# 전략 개선 설계 문서

**날짜:** 2026-05-22  
**목표:** 매수 신호 빈도 증가 + 리스크 관리 중복 제거

---

## 배경

현재 봇은 골든크로스 발생 순간 + RSI < 70 조건을 사용하는데, 이 두 조건이 동시에 충족되는 경우가 매우 드물어 매수가 거의 발생하지 않음. 사용자 목표는 소액으로 자동화 경험을 쌓는 것이며, 하루에도 여러 번 거래가 발생하길 원함.

---

## 변경 사항

### 1. 매수 조건 완화 (`ma_rsi_strategy.py`)

| | 현재 | 변경 |
|---|---|---|
| MA 조건 | 골든크로스 발생 순간 | 단기MA > 장기MA 상태 유지 중 |
| RSI 조건 | RSI < 70 | RSI < 60 |

- 골든크로스 발생 순간만 잡는 대신, 단기MA > 장기MA인 상승 추세 전체에서 매수 가능
- RSI 기준을 60으로 낮춰 과열 전에 더 일찍 진입

### 2. 매도 조건 조정 (`ma_rsi_strategy.py`)

| | 현재 | 변경 |
|---|---|---|
| MA 조건 | 데드크로스 발생 순간 | 단기MA < 장기MA 상태로 전환 |
| RSI 조건 | RSI >= 70 | RSI >= 75 |

- RSI 기준을 75로 상향해 강한 상승장에서 조기 매도 방지
- MA 조건도 상태 기반으로 안정화

### 3. 리스크 관리 중복 제거 (`risk_manager.py`, `trader.py`)

| 위치 | 현재 | 변경 |
|---|---|---|
| RiskManager (3시간) | 익절 +2% + 트레일링 스탑 | 트레일링 스탑만 유지 |
| check_price_alarm (5분) | 익절 +2% + 손절 -3% | 익절 +2% + 손절 -5% |

- 익절은 5분 감시 루프에서만 처리 (더 빠르게 반응)
- RiskManager에서 익절 로직 제거, 트레일링 스탑만 담당
- 손절을 -3% → -5%로 완화해 정상 변동폭에서 손절 방지
